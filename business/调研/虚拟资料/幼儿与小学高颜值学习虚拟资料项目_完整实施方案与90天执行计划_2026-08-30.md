## A3. Go / Adjust / Stop

 

以下全部为**建议测试门槛/待验证**。

 

### GO

 

14–30天内同时满足：

 

 - 完成12次有效访谈；
 - 完成30次明确报价；
 - 至少获得 **6笔真实付款[测]**；
 - 付款客户中至少 **4人实际下载/打开/打印/使用之一[测]**；
 - 至少3条具体使用反馈，不是“很好看”；
 - 无严重内容错误；
 - 无版权来源不明资产；
 - 售后没有形成明显失控；
 - 至少有一个内容类型持续带来真实咨询。

 

进入第二个SKU。

 

### ADJUST

 

出现：

 

 - **2–5笔付款[测]**；
 - 大量“喜欢”，但价格阻力明显；
 - 家长想买，但觉得内容太少/太复杂；
 - 更喜欢低墨版而不是高颜值版；
 - “古诗”不够强，但明显提出英语/识字需求。

 

只调整一个变量：

 

> 人群 / SKU内容 / 包装 / 价格 / 内容表达。

 

不要一次全改。

 

### STOP

 

在：

 

 - 12访谈；
 - 30有效报价；
 - 至少2轮产品表达调整；

 

之后仍只有 **0–1笔真实付款[测]**，且具体使用意愿很弱。

 

停止该SKU。

 

**停止SKU ≠ 停止整个项目。**

| 小学5–6年级家长 | 系统复习 | 对内容准确度要求更高 | 升学/考试 | 独立学习 | 教辅、课程 |
| 小学老师 | 找课堂辅助素材 | 商用/班级授权问题 | 备课 | 课堂 | PPT、教辅 |
| 托管机构 | 批量可打印活动 | 授权和稳定更新 | 课后服务 | 小班 | 自制资料 |

 

### 首发为什么选1–2年级家长

 

不是因为已经证明这是“最大市场”，而是因为：

 

 - 购买者明确；
 - 打印场景容易发生；
 - 古诗视觉表现力强；
 - 可以回避复杂考试结果承诺；
 - 7天SKU足够窄；
 - 古代诗歌版权基础相对容易梳理；
 - 实拍内容天然适合小红书；
 - 后续可以向“第二辑、节气、山水、四季”扩展。

 

这些属于**产品策略假设，仍需验证。**

# F10. 评论/私信FAQ

 

### “适合几年级？”

 

> 当前按小学低年级家庭共读场景设计，不作为同步教材或学校教学替代。

 

### “跟教材同步吗？”

 

> 不按特定出版社教材逐页同步，以独立主题和公开可核验内容制作。

 

### “为什么这么少？”

 

> 第一版只做7天，重点是每页准确、好打印、能真正使用。

 

### “能商用吗？”

 

> 默认仅限购买者个人/家庭使用，不允许转售、网盘传播或用于商业再发行。老师/机构授权另行设计。

 

### “是不是AI做的？”

 

> 部分视觉可使用AI辅助，但学习事实内容经过人工核验，AI不是唯一事实来源；公开发布时按平台规则进行AI内容声明。

 

### “能保证孩子学会吗？”

 

> 不能。产品提供学习材料和使用辅助，不承诺具体学习结果。

 

### “买了能退吗？”

 

> 按商品实际交付方式、消费者法律要求和平台最新售后规则执行。下载异常、文件损坏或与描述不符等问题提供售后处理。

# H2. 单位经济模型

 

定义：

 

```
P = 实付客单价

PF = 平台及支付相关费用

CAC = 当笔订单分摊获客成本

PS = 打印/样品/拍摄成本分摊

CS = 客服售后工时 × 内部小时成本

RR = 退款期望成本

TAX = 税费

LIC = 素材/授权摊销
```

 

那么：

 

```
单笔贡献毛利
= P - PF - CAC - PS - CS - RR - TAX - LIC
```

 

贡献毛利率：

 

```
CM%
= 单笔贡献毛利 / P
```

 

固定成本回本订单量：

 

```
BreakEvenOrders
= 固定投入 / 单笔贡献毛利
```

 

还必须计算：

 

```
创始人时薪贡献
= 90天贡献毛利 / 总投入小时
```

 

否则可能出现：

 

> 看起来有收入，实际上在做低价人工客服。

 

平台费率、税务处理和类目费用不要写死，使用**上线时的平台实际值和专业财税意见**。

## 验证DoD

 

产品v1.0上线之后，项目真正需要追踪的不是：

 

> “今天涨了多少粉”。

 

而是这一条链：

 

> **看见 → 询问 → 明确报价 → 真实付款 → 成功交付 → 实际打印/使用 → 具体反馈 → 第二次购买。**

> **一个能够被继续验证、优化和复制的商业系统。**

 

如果90天后仍只有收藏、点赞、夸“好看”，却没有付款和使用，就应调整甚至停止当前SKU，而不是继续扩充资料库。

 

如果你长期执行这个项目，平台交易和AI标识规则都可能变化，可以定期复核它们而不是靠旧版规则运行。
