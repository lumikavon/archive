## 三、重点账号拆解

### 1. 张咋啦 / Zara Zhang：整体经营模型第一对标

她几乎是当前定位最值得研究的综合样本。公开资料对其内容的总结不是站在程序员视角教授底层技术，而是强调如何把AI真正用进工作和生活，并采用 **Learn by Doing + Learn in Public**：先解决真实问题，再把学习、实践和迭代过程公开。

更值得参考的是，她把内容进一步转成产品，形成：

**真实行动 → 经验 → 内容 → 用户反馈 → 产品。**

我们应该重点拆解：
- 内容如何从真实任务出发，而不是追AI新闻。
- 一次实践如何拆成多篇内容。
- 用户反馈如何反过来形成产品需求。
- Market → Product，而不是先闭门做产品再找流量。
- 如何把职业成长、AI学习和产品建设放在同一人设下。

不应复制的是其海外/硅谷经历和个人履历；我们应复制方法，而不是人设。

参考资料：
- https://lijinma.com/ai/
- https://www.newrank.cn/rankai/xiaohongshu/5/1/2025-08-31

### 2. NPointer：AI Agent × 求职重合度最高

公开榜单描述显示其内容同时涉及算法、开源、AI分享、职业就业规划以及Agent项目开发。

这意味着它天然连接了：**AI + Agent项目 + 职业能力证明 + 求职。**
重点研究：
- 哪类Agent项目同时吸引技术学习与求职人群。
- Agent项目如何转成简历上的真实能力证据。
- 用户评论更多在问“怎么学”还是“怎么找工作”。
- 项目开发与职业就业规划之间如何自然转化。

这里最值得发展的产品方向是：

**AI Agent求职作品集：真实Agent项目 → 项目证据 → 简历表达 → STAR案例 → 面试演示。**

它比传统简历资料更有差异化，也比泛Agent教程更接近明确结果。

参考资料：https://newrank.cn/rankai/xiaohongshu/10/1/2025-08-27

### 3. Gilbert🍃：AI × 知识工作者效率

公开资料显示其定位本身就是“产品经理 + Productivity + AI”。它的重要性在于，我们的目标用户并不是AI科研人员，而是希望用AI提高工作效率的知识工作者。

值得复制的内容结构：

**工作场景 → 问题 → 工具 → 工作流 → 成果。**

重点观察：
- 如何把产品经理身份和AI内容融合。
- 如何选择高频、可保存的工作问题。
- 工具内容如何避免沦为简单“工具推荐”。
- 工作流前后对比如何展示实际价值。

参考资料：https://www.newrank.cn/profile/xiaohongshu/634c09340000000012025f9e?from=ranklist

### 4. 花叔：AI项目产品化第一对标

花叔已经形成较完整的：**内容 → 开源项目 → 产品 → 图书 → 社区/IP** 结构。

其真正值得学习的不是某个AI工具教程，而是一个原则：**内容里尽量存在真实成果物。**
以后我们的笔记也应尽量附带或展示：
- 工作流
- 模板
- Excel/表格
- Skill
- Agent
- Demo
- Checklist

而不是只有观点和截图。

参考资料：https://p.timeshining.com/detail/html/alchaincyf/huashu-design

### 5. 机器坏人（AI版）：学习型IP与职业转型叙事

其“AI产品经理学习笔记”定位值得新号学习。关键不是把自己包装成AI专家，而是把“正在成为某一种人”的过程公开化。

这类定位比“AI Agent大师”更可信。我们的账号也更适合采用：

**“我在用AI Agent重构100个真实工作流程。”**

用户可以跟着项目和能力一起成长。

参考资料：https://www.newrank.cn/rankai/xiaohongshu/14/7/2025-09-01

### 6. 西里森森：知识库型内容产品

它的参考价值在于把持续输出进一步沉淀为AI学习知识库。

可借鉴路径：

**免费内容 → 系列内容 → 数据库 → 知识库 → 付费产品。**

这与我们的“个人知识库/研究助理Agent搭建包”高度匹配。

参考资料：https://www.sina.cn/media/6593383189

### 7. 子木聊AI：纯Agent垂直号

其公开定位直接聚焦AI智能体教学。我们重点不是复制培训型表达，而是研究评论区里的真实问题：安装、模板、零基础、知识库、工具调用、部署、工作流等。
这些问题可以直接进入我们的69元Agent项目包需求库，例如：
- 怎么安装/配置？
- 有没有可直接复用的模板？
- 零基础能不能做？
- 怎么接知识库？
- 怎么让Agent调用工具？
- 怎么部署与排错？
- 能不能直接给完整工作流？

参考资料：https://newrank.cn/profile/xiaohongshu/5ebaacb7000000000100566c?from=ranklist

### 8. 职帅：求职搜索关键词与内容树

公开账号资料显示，它已经形成较标准的职场内容体系：职场管理、职场技能、个人成长、职业规划、求职面试、职场资源。

它最适合用来研究 **搜索关键词布局**。例如“面试”不能只作为一个大词，而要拆成：
- 面试自我介绍
- STAR
- 薪资谈判
- 空窗期
- 离职原因
- 反问面试官
- Offer比较
- 入职准备

这些长尾问题可以作为我们30%求职内容的搜索流量池，但不应演化成泛职场鸡汤。

参考资料：https://www.newrank.cn/profile/xiaohongshu/61720edd000000000201fa27?from=ranklist

### 9. 超级简历 WonderCV：求职产品化标杆

它并非最适合学习个人IP，但非常适合研究“求职怎么商品化”。公开产品结构覆盖简历模板、AI简历生成、JD匹配、简历优化、校招信息、面试辅导、职业规划等。

其商业链路可以概括为：

**Content → Tool → Service。**

我们的差异化不应是正面竞争“简历”，而应向前扩展到完整职业工作流：

**JD Agent → 经历证据库 → STAR → 简历 → 面试 → Offer决策。**

## 五、我们的差异化机会

研究这些账号后，结论反而更清晰：我们不应该把账号定义成“AI教程号”，也不应该定义成“求职号”，而应坚持：

# AI职场工作流

我们位于三类成熟内容之间：

**AI工具博主**
↓ 缺真实工作场景与职业结果

**我们：AI Agent × 工作流 × 职业**

↑ 缺技术产品化与完整工作系统
**传统求职博主**

这块交叉区域比“AI工具大全”和“简历教程”更有差异化空间。

### 最值得发展的完整产品链

**AI Agent项目训练**
→ **真实项目作品**
→ **经历证据库**
→ **AI简历/JD匹配**
→ **面试STAR**
→ **Offer决策**
→ **入职后AI工作流**

因此，我们真正出售的不是孤立的“AI资料”或者“求职资料”，而可以逐渐形成：

> **AI时代知识工作者的职业操作系统。**

这也是未来内容、数字产品、Agent产品和软件产品能够统一的主轴。
## 六、下一步建议

下一步不应继续扩充账号数量，而应对TOP10对标账号做笔记级采样：

- 每个账号抽取20—30篇代表笔记。
- 总样本约200—300篇。
- 记录标题、封面、发布日期、互动、关键词、内容结构、用户问题、CTA、产品形态、价格、评论区购买前置信号。
- 单独标注“项目实战、失败复盘、工具演示、职业决策、求职搜索词”五类内容。
- 统计TOP内容共同特征，反推我们的前30篇内容和首批SKU。

最终目标不是复制爆款标题，而是建立一套可持续的 **对标账号→笔记数据库→需求信号→选题→产品→复盘** 经营闭环。
